# Build system for VizTR Meet\n# ==========================\n\nThis file provides instructions for building, testing, and deploying\nthe VizTR Meet real-time translation platform.\n\n## Quick Start\n\n### 1. Clone the repository\n\n```bash\ngit clone https://github.com/your-org/viztr-meet.git\n\ncd viztr-meet\n```\n\n### 2. Install dependencies\n\n```bash\npip install -r requirements.txt\n```\n\n### 3. Set up environment variables\n\n```bash\ncp .env.example .env\n\n# Edit the .env file and fill in your API keys for whichever fallback providers you enable\n```\n\n### 4. Run tests\n\n```bash\npytest\n```\n\n### 5. Run the application\n\n```bash\nuvicorn src/viztrmeet.main:app --reload --port 8000\n```\n\n## Development Commands\n\n### Code Quality\n\n```bash\n# Format code\nblack src/viztrmeet\n\n# Sort imports\nisort src/viztrmeet\n\n# Lint code\nruff check src/viztrmeet --fix\n\n# Type checking\nmypy src/viztrmeet\n```\n\n### Testing\n\n```bash\n# Unit tests\npytest tests/unit/\n\n# Integration tests\npytest tests/integration/\n\n# All tests\npytest\n```\n\n### Build and packaging\n\n```bash\n# Build distribution\npython -m build\n\n# Local install for development\npip install -e .\n\n# Upload to PyPI (requires authentication)\ntwine upload dist/*\n```\n\n## Docker setup\n\n### Quick start with Docker\n\n```bash\n# Build the Docker image\nDocker build -t viztr-meet .\n\n# Run the container\nDocker run -p 8000:8000 viztr-meet\n```\n\n### Development with Docker Compose\n\n```bash\n# Create docker-compose.yml\ncat > docker-compose.yml << 'EOF'\nversion: '3.8'\nservices:\n  viztr-meet:\n    build: .\n    ports:\n      - '8000:8000'\n    env_file:\n      - .env\n    volumes:\n      - ./src:/app/src\n      - ./tests:/app/tests\n    depends_on:\n      - livekit\n\n  livekit:\n    image: livekit/agent:latest\n    ports:\n      - '7800:7800'\n    environment:\n      LIVEKIT_LOG_LEVEL: info\nEOF\n\n# Run services\nDocker compose up --build\n```\n\n### Running tests in Docker\n\n```bash\n# Build test image\nDocker build -t viztr-meet-test -f Dockerfile.test .\n\n# Run tests\nDocker run viztr-meet-test pytest\n```\n\n## Project Structure\n\n```\nviztr-meet/\n├── src/\n│   └── viztrmeet/          # Python package\n│       ├── core/           # Core components\n│       ├── routes/         # HTTP/WS endpoints\n│       ├── services/       # Provider interfaces\n│       └── main.py        # FastAPI entrypoint\n├── agent/                   # Integration tests\n├── docs/                    # Documentation\n│   ├── api.md\n│   ├── architecture.md\n│   └── development.md\n├── README.md              # Project README\n├── CONTRIBUTING.md        # CI/CD pipelines\n```\n\n## Testing\n\n### Unit tests\n\nUnit tests are located in `tests/unit/` and test individual components.\n\n```bash\npytest tests/unit/\n```\n\n### Integration tests\n\nIntegration tests are located in `tests/integration/` and test system interactions.\n\n```bash\npytest tests/integration/\n```\n\n### Performance tests\n\nPerformance tests are located in `performance/`:\n\n```bash\npytest performance/\n```\n\n### Code coverage\n\nThis project uses `coverage.py` for code coverage reporting.\n\n```bash\n# Run tests with coverage\npython -m coverage run -m pytest tests/\n\n# Generate coverage report\npython -m coverage report\n\n# Generate HTML coverage report\npython -m coverage html\n```\n\n## Deployment\n\n### Docker deployment\n\nBuild and run the application with Docker.\n\n```bash\n# Build the Docker image\nDocker build -t viztr-meet .\n\n# Run the application\nDOCKER_BUILDKIT=1 Docker compose up --build\n```\n\n### Kubernetes deployment\n\nDeploy to Kubernetes using `kustomization.yaml`.\n\n```bash\n# Apply kustomization\nkubectl apply -k .\n```\n\n### Cloud deployment\n\nDeploy to major cloud providers:\n\n* **AWS:** ECS/EKS\n* **Google Cloud:** Cloud Run\n* **Azure:** Azure Container Instances\n* **DigitalOcean:** App Platform\n\n## Troubleshooting\n\n### Common issues\n\n| Problem | Solution |\n|---------|----------|\n| \"ModuleNotFoundError: No module named viztrmeet\" | Ensure the package is installed with `pip install -e .` |\n| \"Connection refused\" | Check if the application is running and port is available |\n| JWT token validation errors | Verify the secret key matches the one in .env |\n| VAD model download failures | Check internet connection and model availability |\n\n### Getting help\n\n* GitHub Issues: https://github.com/your-org/viztr-meet/issues\n* Discord: https://discord.gg/viztr-meet\n* Email: support@viztr-meet.com\n\n## Contributing\n\nThis project welcomes contributions!
